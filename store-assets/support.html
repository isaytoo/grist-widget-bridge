Grist Widget Bridge v2.0

Aide & Support

Tout ce qu'il faut savoir pour installer, configurer et dépanner l'extension.

Installation rapide

  • 1
    Installez l'extension depuis le Chrome Web Store.
  • 2
    Ouvrez votre page Grist dans un onglet → cliquez l'icône de l'extension → « + Comme instance Grist ».
  • 3
    Ouvrez la page de votre widget dans un onglet → cliquez l'icône → « + Comme widget ».
  • 4
    Rechargez les onglets concernés. L'extension est active.

Ce que fait l'extension

Elle corrige deux problèmes courants des widgets personnalisés Grist hébergés sur un domaine externe :

✅ CORS sur l'API Grist — l'upload de pièces jointes depuis le widget fonctionne via un pont postMessage injecté dans la page Grist (même origine que l'API).

✅ localStorage bloqué — l'extension corrige la DOMException "The operation is insecure" via un proxy transparent vers chrome.storage.

Configuration avancée

Clic-droit sur l'icône → Options, ou bouton ⚙ dans le popup. Vous pouvez :

  • Ajouter / supprimer des instances Grist
  • Ajouter / supprimer des domaines de widgets (wildcards /* supportés)
  • Réinitialiser la configuration par défaut

Questions fréquentes

Le popup indique « Aucune règle » sur ma page Grist — que faire ?
Cliquez « + Comme instance Grist » dans le popup, puis rechargez l'onglet. Si c'est déjà fait, vérifiez que l'URL de votre Grist correspond bien à celle listée dans les options (sans slash final).
L'upload de pièces jointes ne fonctionne toujours pas.
Assurez-vous que : (1) la page Grist est bien configurée comme instance, (2) la page widget est bien configurée comme widget, (3) vous êtes connecté à votre Grist (la session cookie doit être active). Rechargez les deux onglets après toute modification de config.
L'extension ralentit-elle mon navigateur ?
Non. Elle ne s'active que sur les URLs que vous avez explicitement configurées. Sur tous les autres sites, elle est inactive.
Fonctionne-t-elle avec Edge ou Brave ?
Oui — tout navigateur Chromium (Chrome, Edge, Brave, Opera) est compatible avec les extensions Chrome Web Store.
Mes données sont-elles envoyées quelque part ?
Non. L'extension ne contacte aucun serveur tiers. Seules vos listes d'URLs sont stockées localement via chrome.storage.sync. Voir notre politique de confidentialité.
Comment désinstaller l'extension ?
Rendez-vous sur chrome://extensions → bouton Supprimer à côté de Grist Widget Bridge.
